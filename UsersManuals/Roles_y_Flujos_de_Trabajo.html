Roles y Flujos de Trabajo

Bar Demo — Febrero 2026

Este documento describe los tres perfiles de usuario del sistema, sus permisos, y el flujo de trabajo diario de cada uno en el contexto de un bar/restaurante.

1. Perfiles de Usuario

Rol Descripcion Acceso principal
Admin Dueno / Gerente del negocio Todo: usuarios, caja, POS, inventario, compras, facturas, reportes, configuracion
Cajero Operador de caja / POS Abrir/cerrar caja (con contrasena), operar POS, crear facturas, ver productos
User Empleado basico (mesero) Ver dashboard, ver productos. No puede abrir caja ni operar POS

4. Flujo de Trabajo: Admin

Dia tranquilo (lunes-martes, opera solo)

  1. Login → Ingresar al sistema
  2. Dashboard → Revisar estadisticas del dia anterior
  3. Caja Registradora → Abrir caja (verificar contrasena + ingresar monto inicial)
  4. POS → Crear ordenes, agregar productos, cobrar ventas
  5. Inventario / Movimientos → Revisar stock bajo, hacer ajustes manuales
  6. Ordenes de Compra → Crear OC a proveedores si falta stock, recibir mercancia con checklist
  7. Facturas → Crear facturas manuales si el cliente las solicita
  8. Reportes → Ver reporte diario al cierre
  9. Caja Registradora → Cerrar caja (conteo fisico, verificar diferencia)

Dia pico (jueves-sabado, con equipo)

  1. Login → Ingresar al sistema
  2. Usuarios → Verificar que los cajeros existen en el sistema
  3. Caja Registradora → Abrir caja para cada cajero que va a operar
  4. Supervision → Monitorear dashboard y reportes en tiempo real
  5. Inventario → Monitorear stock, hacer ajustes si es necesario
  6. Ordenes de Compra → Recibir mercancia con checklist de verificacion
  7. Cierre → Supervisar cierre de caja de cada cajero
  8. Reportes → Reporte diario consolidado

5. Flujo de Trabajo: Cajero

  1. Login → Ingresar con sus credenciales
  2. Caja Registradora → Abrir caja (ingresa contrasena + monto inicial)
  3. POS → Crear orden (verifica contrasena la primera vez)
  4. POS → Agregar productos al carrito haciendo clic en las tarjetas
  5. POS → Cobrar venta: seleccionar metodo de pago (efectivo / tarjeta / transferencia / QR)
  6. POS → Manejar multiples ordenes en tabs si hay varias mesas
  7. POS → Cancelar orden si el cliente lo solicita (devuelve stock)
  8. Facturas → Crear factura manual si el cliente la solicita
  9. Caja Registradora → Cerrar caja al final del turno (conteo fisico, ver diferencia)

7. Notas Importantes

TemaDetalle
Creacion de usuariosSolo el Admin puede crear usuarios desde Admin → Usuarios. Al crear, se asigna nombre, email, contrasena y rol.
Contrasena en cajaTanto Admin como Cajero deben verificar su contrasena al abrir caja. Esto previene que alguien abra caja sin autorizacion.
Bloqueo por intentosDespues de 3 intentos fallidos de contrasena (en caja, POS o facturas), el sistema cierra la sesion automaticamente.
InactividadEl sistema cierra sesion automaticamente despues de 60 segundos de inactividad (con advertencia a los 50 segundos).
POS requiere caja abiertaNo se puede cobrar una orden si no hay una caja abierta. El sistema muestra un aviso y boton para ir a abrir caja.
Cancelar ordenAl cancelar una orden en POS, el stock se devuelve automaticamente al inventario.
Recepcion de comprasAl recibir una orden de compra, se usa un checklist por producto: cantidad recibida, cantidad devuelta y motivo de devolucion.
